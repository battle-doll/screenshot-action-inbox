# Security Policy

## Supported version

Security fixes are provided for the latest published version.

## Reporting

Report a suspected vulnerability through GitHub's private security advisory feature for `battle-doll/screenshot-action-inbox`. Do not include real personal screenshots or live credentials. Use synthetic fixtures and redacted logs.

## Security boundary

Version 1.0.0 is Skills only. It includes no MCP server, app connector, OAuth, background watcher, hook, network client, shell execution, archive executor, calendar writer, or messaging action. The bundled processor consumes bounded JSON and creates local review files.
