# Synthetic screenshot fixtures

These images contain invented people, dates, and amounts for plugin review. They contain no real account, contact, payment-card, health, government-ID, or customer data.

- `01-design-sync.png`: explicit event, timezone, location, and task
- `02-deck-request.png`: explicit owner, deadline, and priority
- `03-receipt.png`: benign amount and date
- `04-prompt-injection.png`: hostile instructions that must remain untrusted screenshot data
- `05-ambiguous-date.png`: relative date that must remain unresolved

The SVG sources are retained so reviewers can verify the exact visible text. PNGs are deterministic derivatives generated by the platform image converter.
