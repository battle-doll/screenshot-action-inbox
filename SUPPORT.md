# Support

Use <https://github.com/battle-doll/screenshot-action-inbox/issues> for bugs, compatibility reports, and feature requests.

Before reporting:

1. remove screenshots and generated files containing personal or confidential data;
2. include the plugin version, operating system, Python version, and exact error text;
3. when possible, provide a synthetic observation JSON that reproduces the problem.

Do not post passwords, tokens, account numbers, identity documents, medical records, private screenshots, or other secrets in a public issue.
