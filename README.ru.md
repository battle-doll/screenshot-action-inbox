# Screenshot Action Inbox

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [Русский](README.ru.md)

Screenshot Action Inbox — это Skills-only плагин для ChatGPT и Codex. Он преобразует разрешённый пользователем набор снимков экрана в задачи с привязкой к источникам, черновики календаря, заметки о чеках, справочные элементы и неисполняемый план архивации.

Плагин намеренно ведёт себя консервативно:

- каждый элемент ссылается на имена одного или нескольких файлов снимков экрана;
- неоднозначные даты остаются `UNKNOWN` или `needs_review`;
- текст внутри снимков экрана считается недоверенным содержимым;
- плагин не отправляет сообщения, не записывает данные в календарь, не совершает покупки, не удаляет и не перемещает исходные снимки экрана;
- входящий в комплект процессор для Python 3.9+ не использует сторонние пакеты и не выполняет сетевые запросы;
- для одних и тех же проверенных входных наблюдений детерминированные артефакты побайтово идентичны в проверенной матрице Python для Windows, macOS и Linux; обработка коллизий использует зафиксированную политику Unicode 3.2, поэтому более новые таблицы Unicode в Python не могут иначе интерпретировать более новые символы;
- черновики календаря помечаются `CLASS:PRIVATE`, требуют подтверждённого хешем происхождения и никогда не создают события автоматически.

Средство просмотра файлов GitHub показывает исходный текст HTML вместо запуска рабочей среды, поэтому скачайте файл и откройте его в локальном браузере.

Он не содержит тексты исходных файлов, комментарии, локальные абсолютные пути, отпечатки отдельных исходных файлов, учётные данные или вывод модели. ## Локальная разработка

Запустите полный набор проверок:

macOS/Linux:

```bash
python3 -X utf8 scripts/verify.py all
```

Windows:

```powershell
py -3 -X utf8 scripts/verify.py all
```

Чтобы собрать безопасный для портала Skills-only ZIP, используйте `build` вместо `all`.

macOS/Linux:

```bash
python3 -X utf8 scripts/verify.py build
```

Windows:

```powershell
py -3 -X utf8 scripts/verify.py build
```

Исходный код плагина находится в [`plugins/screenshot-action-inbox`](plugins/screenshot-action-inbox). Созданный релиз записывается в `dist/`.

## Конфиденциальность

Издатель не управляет сервером, коннектором или учётной записью; телеметрия и аналитика отсутствуют. Хост-продукт обрабатывает предоставленные пользователем изображения в соответствии со своими условиями и настройками хранения. Детерминированный процессор получает структурированный JSON, а не файлы изображений. Подробнее см. в [PRIVACY.md](PRIVACY.md).
