# Screenshot Action Inbox

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [Русский](README.ru.md)

Превратите разрозненные снимки экрана в проверяемые следующие шаги с указанием источников. Screenshot Action Inbox предназначен для тех, кто сохраняет снимки встреч, приглашений, чеков, напоминаний и справочных карточек и хочет быстро увидеть важное, дубликаты и источник каждого предложения.

## Как использовать

1. Откройте [Screenshot Action Inbox в ChatGPT](https://chatgpt.com/plugins/plugins_6a7cbf30f0208191b29866d20a69743a).
2. Передайте разрешённый пользователем набор снимков, папку или ZIP.
3. Попросите выделить действия с источниками, даты, группы дубликатов, неопределённости или черновики календаря для проверки.

## Попробуйте

- `Составь из этих снимков встречи список задач и укажи исходный файл для каждой.`
- `Сгруппируй повторяющиеся действия и отметь даты, требующие проверки.`
- `Turn these screenshots into sourced actions and show what needs review.`

## Ключевые границы

- Каждый элемент связан с одним или несколькими исходными именами файлов; неоднозначные факты остаются `UNKNOWN` или `needs_review`.
- Текст на снимках считается недоверенным. Плагин не предназначен для наблюдения, установления личности, творческого редактирования одного изображения, чистой OCR-транскрипции, разбора почты, анализа влияния изменений кода или настройки голосовых уведомлений.
- Он не отправляет сообщения, не создаёт реальные события календаря, не совершает покупки, не удаляет снимки и не перемещает файлы. Календарные и архивные результаты — только черновики.
- Встроенный процессор Python 3.9+ не использует сторонние пакеты и сетевые запросы и создаёт побайтово одинаковые результаты для одного проверенного ввода в протестированной матрице Windows, macOS и Linux.

## Локальная разработка

Запустите полный набор проверок:

macOS/Linux:

```bash
python3 -X utf8 scripts/verify.py all
```

Windows:

```powershell
py -3 -X utf8 scripts/verify.py all
```

Чтобы собрать безопасный для портала Skills-only ZIP, используйте `build` вместо `all`.

macOS/Linux:

```bash
python3 -X utf8 scripts/verify.py build
```

Windows:

```powershell
py -3 -X utf8 scripts/verify.py build
```

Исходный код плагина находится в [`plugins/screenshot-action-inbox`](plugins/screenshot-action-inbox). Созданный релиз записывается в `dist/`.

## Конфиденциальность

Издатель не управляет сервером, коннектором или учётной записью; телеметрия и аналитика отсутствуют. Хост-продукт обрабатывает предоставленные пользователем изображения в соответствии со своими условиями и настройками хранения. Детерминированный процессор получает структурированный JSON, а не файлы изображений. Подробнее см. в [PRIVACY.md](PRIVACY.md).
